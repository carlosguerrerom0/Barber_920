# Guía de entrevista con el cliente

**Objetivo:** obtener la información necesaria para validar el alcance y convertir el borrador en requerimientos definitivos.

**Entrevista realizada el 3 de octubre de 2026:** respuestas y preguntas pendientes en la [minuta](minuta-entrevista-cliente-2026-10-03.md). Esta guía se conserva como cuestionario original.

## Situación actual

1. ¿Cómo reciben y registran actualmente las citas?
2. ¿Qué problemas ocurren con mayor frecuencia?
3. ¿Quién consulta y administra las reservaciones?
4. ¿Qué información necesitan ver rápidamente durante la jornada?
5. ¿Utilizan actualmente alguna agenda, aplicación o libreta?

## Sucursales

6. ¿Cuál es el nombre, dirección, teléfono y horario de cada sucursal?
7. ¿Las tres sucursales ofrecen los mismos servicios?
8. ¿Los horarios cambian según la sucursal o el día?
9. ¿Existen días de descanso o cierres especiales?
10. ¿Desean incluir un mapa o enlace de ubicación?

## Servicios y disponibilidad

11. ¿Qué servicios se podrán reservar?
12. ¿Cuál es el precio y duración aproximada de cada servicio?
13. ¿Se necesita tiempo adicional entre citas?
14. ¿El cliente debe seleccionar un barbero?
15. ¿Cada barbero maneja su propia disponibilidad?
16. ¿Con cuánta anticipación se puede reservar?
17. ¿Cuántas citas simultáneas puede aceptar una sucursal?

## Registro de citas

18. ¿Qué datos debe proporcionar el cliente?
19. ¿El cliente necesita crear una cuenta o puede reservar como invitado?
20. ¿Cómo se confirmará la reservación?
21. ¿Se enviarán recordatorios? En caso afirmativo, ¿por qué medio?
22. ¿El cliente podrá modificar o cancelar una cita?
23. ¿Qué reglas aplican para retardos, cancelaciones o clientes que no se presentan?

## Administración

24. ¿Qué personas tendrán acceso administrativo?
25. ¿Qué acciones podrá realizar un administrador?
26. ¿Necesitan filtrar las citas por fecha, sucursal, servicio o barbero?
27. ¿Qué estados debe manejar una cita?
28. ¿Requieren reportes o estadísticas? ¿Cuáles?
29. ¿Quién podrá bloquear fechas u horarios?

## Diseño y validación

30. ¿Cuentan con logotipo, colores, fotografías y tipografías autorizadas?
31. ¿Qué sitios o aplicaciones les gustan como referencia?
32. ¿Qué información debe aparecer en la página principal?
33. ¿Quién aprobará los prototipos y la versión final?
34. ¿Con qué frecuencia pueden revisar avances?
