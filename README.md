# Sistema Web de Agendamiento y Sucursales - Barber 920

Proyecto académico para analizar, diseñar y desarrollar un sistema web que facilite la consulta de sucursales y el agendamiento de citas de Barber 920.

## Estado del proyecto

**Fase 2: levantamiento de requerimientos y diseño inicial.**

El alcance y los requisitos incluidos en este repositorio son preliminares hasta que sean revisados y validados con el representante de Barber 920.

## Problema

Se necesita una herramienta digital que permita a los clientes consultar información de las sucursales y reservar un horario de atención desde un mismo sitio. El sistema también busca apoyar la organización básica de las citas.

## Objetivo general

Desarrollar un sistema web adaptable a computadoras y celulares que permita consultar sucursales, revisar disponibilidad, registrar citas y administrar reservaciones de forma básica.

## Módulos previstos

- Información general de Barber 920.
- Consulta y ubicación de sucursales.
- Catálogo de servicios.
- Consulta de fechas y horarios disponibles.
- Registro de citas.
- Administración básica de reservaciones.
- Interfaz adaptable para computadora y celular.

Las actividades se registran mediante GitHub Issues. Cada tarea debe indicar su propósito, criterios de aceptación y evidencia esperada. Los cambios importantes del alcance o funcionamiento deberán validarse con el cliente antes de considerarse definitivos.
