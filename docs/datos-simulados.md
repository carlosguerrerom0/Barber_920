## Reglas

- **Horarios:** cada 30 minutos desde las 10:00. El último depende de cuánto dura el servicio y de la hora de cierre.
- **Anticipación:** para el mismo día se piden dos horas.
- **Un cliente por barbero:** cada barbero atiende una cita a la vez y no trabaja en su día de descanso.
- **Sin preferencia:** si el cliente no elige barbero, se le asigna el primero que esté libre.
- **Datos del cliente:** nombre y teléfono.
- **Estados:** las citas nuevas empiezan como Pendiente y el administrador las cambia.
- **Avisos:** no se mandan mensajes reales.
